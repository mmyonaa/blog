그래프는 트리보다 일반화된 자료구조다. 트리는 사이클이 없고 부모-자식 관계가 명확하지만, 그래프는 정점 사이에 임의의 간선이 있고 사이클도 허용된다. 그래프를 방문하는 대표적인 두 방법이 너비 우선 탐색(BFS, Breadth-First Search)과 깊이 우선 탐색(DFS, Depth-First Search)이다.

## BFS — 가까운 노드부터

BFS는 시작 정점에서 가까운 노드부터 차례로 방문한다. 큐(Queue)를 사용해, 한 노드를 방문하면 인접한 미방문 노드를 모두 큐에 넣고 하나씩 꺼내며 반복한다. FIFO 구조라 시작점에서 거리(간선 수)가 같은 노드들이 같은 레벨 단위로 묶여 순서대로 방문된다. 이 성질 때문에 가중치 없는 그래프의 최단 경로를 구할 때 BFS를 쓴다.

## DFS — 갈 수 있는 데까지 간다

DFS는 한 방향으로 갈 수 있는 데까지 깊이 들어간 뒤, 더 갈 곳이 없으면 되돌아와 다른 방향을 탐색한다. 스택(Stack) 또는 재귀 호출로 구현하며, 재귀 호출 자체가 시스템 스택을 쓰므로 자연스럽게 DFS 구조가 된다. 이진 트리의 전위·중위·후위 순회도 DFS의 한 형태다.

## 방문 배열이 하는 일

두 방법 모두 방문한 노드를 다시 방문하지 않도록 visited 배열을 유지한다. 그래프는 사이클이 있을 수 있어 이 배열이 없으면 무한 루프에 빠진다. 트리 순회에서는 부모로 되돌아가는 간선이 없어 이 문제가 드러나지 않았을 뿐이다.

## 코드로 보는 차이

인접 리스트로 표현한 그래프를 BFS로 방문하는 Python 예시다.

```python
from collections import deque

graph = {
    "A": ["B", "C"],
    "B": ["A", "D"],
    "C": ["A", "D"],
    "D": ["B", "C", "E"],
    "E": ["D"],
}

def bfs(graph, start):
    visited = {start}
    queue = deque([start])
    order = []
    while queue:
        node = queue.popleft()
        order.append(node)
        for n in graph[node]:
            if n not in visited:
                visited.add(n)
                queue.append(n)
    return order
```

같은 그래프를 DFS로 방문하면 A, B, D, C, E 순서가 나와 BFS의 A, B, C, D, E와 달라진다. 인접 리스트에 이웃을 나열한 순서가 방문 순서에 그대로 영향을 준다.

## 시험에서 자주 나오는 포인트

인접 행렬은 두 노드의 연결 여부를 바로 확인하지만 정점 수의 제곱에 비례하는 공간을 쓰고, 인접 리스트는 공간 효율이 좋아 간선이 적은 그래프에 적합하다. 시간 복잡도는 인접 리스트 기준으로 BFS, DFS 모두 O(V+E)다. 가중치 없는 그래프의 최단 경로는 BFS로 구하며 DFS는 이를 보장하지 않는다. BFS는 레벨 단위 탐색(예: 최소 홉 수 계산)에, DFS는 백트래킹이나 위상 정렬에 자주 쓰인다. 실기에서는 그래프와 시작 정점을 주고 방문 순서를 손으로 추적하는 문제가 자주 나오므로, 인접 리스트의 나열 순서를 놓치지 않아야 한다.
