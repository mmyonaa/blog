분류 모형의 성능은 "몇 개 맞췄나"만으로는 판단하기 어렵다. 어떤 종류의 실수를 얼마나 했는지 보여주는 표가 혼동행렬(confusion matrix)이고, 대부분의 평가지표가 여기서 파생된다.

## 혼동행렬의 구조

이진 분류에서 실제 값과 예측 값을 교차하면 네 칸이 나온다. 양성(Positive)을 관심 대상 클래스로 둔다.

| | 예측 양성 | 예측 음성 |
|---|---|---|
| 실제 양성 | TP (참 양성) | FN (거짓 음성) |
| 실제 음성 | FP (거짓 양성) | TN (참 음성) |

이름은 "예측이 맞았나(True/False) + 예측한 값(Positive/Negative)"으로 읽으면 된다. FP는 음성을 양성으로 잘못 예측한 경우, FN은 양성을 놓친 경우다.

## 핵심 지표

```text
정확도(Accuracy)   = (TP + TN) / (TP + TN + FP + FN)
정밀도(Precision)  = TP / (TP + FP)
재현율(Recall)     = TP / (TP + FN)
특이도(Specificity) = TN / (TN + FP)
F1                 = 2 * Precision * Recall / (Precision + Recall)
```

- 정확도: 전체 중 맞춘 비율.
- 정밀도: 양성이라고 예측한 것 중 실제 양성인 비율. 틀린 경보를 줄이고 싶을 때 본다.
- 재현율(민감도, Sensitivity, TPR): 실제 양성 중 찾아낸 비율. 놓치면 안 될 때 본다.
- 특이도: 실제 음성 중 음성으로 맞춘 비율.
- F1: 정밀도와 재현율의 조화평균. 둘 중 하나가 낮으면 F1도 크게 낮아진다.

## 계산 예시

100건 중 TP=40, FN=10, FP=20, TN=30이라고 하자.

```text
Accuracy    = (40 + 30) / 100 = 0.70
Precision   = 40 / (40 + 20)  = 0.667
Recall      = 40 / (40 + 10)  = 0.80
Specificity = 30 / (30 + 20)  = 0.60
F1          = 2*40 / (2*40 + 20 + 10) = 80 / 110 = 0.727
```

F1은 `2TP / (2TP + FP + FN)`으로도 계산할 수 있어 검산에 편하다.

## 지표를 고르는 기준

정확도는 클래스가 불균형하면 쉽게 속는다. 양성이 1%인 데이터에서 무조건 음성이라고 답하는 모형도 정확도가 99%가 된다. 이때는 재현율과 정밀도를 함께 봐야 한다.

- 질병 진단, 사기 탐지처럼 놓친 양성의 비용이 크면 재현율을 우선한다.
- 스팸 필터처럼 정상을 잘못 걸러내는 비용이 크면 정밀도를 우선한다.
- 둘의 균형이 필요하면 F1을 쓴다.

정밀도와 재현율은 보통 상충한다. 분류 임계값을 낮추면 양성 예측이 늘어 재현율은 오르지만 정밀도는 떨어지는 경향이 있다. 임계값을 바꿔가며 TPR(재현율)과 FPR(1 - 특이도)의 관계를 그린 것이 ROC 곡선이고, 그 아래 면적이 AUC다. AUC는 1에 가까울수록, 0.5면 무작위 수준으로 해석한다.

## 시험 포인트

- 정밀도의 분모는 예측 양성(TP+FP), 재현율의 분모는 실제 양성(TP+FN)이다. 가장 자주 헷갈리는 부분이다.
- 재현율, 민감도, TPR은 같은 지표다. FPR은 1 - 특이도다.
- F1은 산술평균이 아니라 조화평균이다.
- 불균형 데이터에서 정확도만 높은 모형은 좋은 모형이 아닐 수 있다.
- 표의 행·열 배치는 자료마다 다를 수 있으니, 문제의 축 정의(실제/예측)를 먼저 확인하고 TP·FP·FN·TN을 짚는다.
