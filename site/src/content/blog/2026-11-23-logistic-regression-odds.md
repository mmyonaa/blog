## 왜 선형회귀로는 안 되나

합격/불합격, 이탈/유지처럼 결과가 0 또는 1인 변수를 선형회귀로 예측하면 값이 0보다 작거나 1보다 크게 나올 수 있다. 확률로 해석할 수 없는 값이다. 또 이진 종속변수는 오차의 분산이 일정하다는 가정도 만족하기 어렵다. 로지스틱 회귀는 선형식의 결과를 0~1 사이로 눌러 담아 "양성일 확률"을 직접 출력하는 분류 모형이다.

## 오즈와 로짓

확률 p를 오즈(odds)로 바꾸는 것이 출발점이다.

```text
odds = p / (1 - p)
logit(p) = ln(odds) = b0 + b1*x1 + b2*x2 + ...
```

오즈는 "일어나지 않을 확률 대비 일어날 확률"이다. p=0.5이면 오즈 1, p=0.8이면 오즈 4, p=0.2이면 오즈 0.25다. 오즈는 0 이상 무한대까지 가고, 여기에 자연로그를 씌운 로짓은 -무한대에서 +무한대까지 가므로 우변의 선형식과 범위가 맞는다. 모형은 이 로짓을 설명변수의 선형 결합으로 둔다.

## 시그모이드 함수

로짓식을 p에 대해 풀면 시그모이드(sigmoid, 로지스틱 함수)가 된다.

```text
p = 1 / (1 + e^(-z)),  z = b0 + b1*x1 + ...
```

z가 0이면 p는 0.5이고, z가 커질수록 1에, 작아질수록 0에 가까워지는 S자 곡선이다. 분류할 때는 p가 임계값(보통 0.5)을 넘으면 양성으로 판정한다. 임계값을 바꾸며 성능을 보는 도구가 앞서 다룬 ROC 곡선이다.

## 계수와 오즈비 해석

선형회귀에서는 계수가 "x가 1 늘 때 y의 변화량"이었지만, 로지스틱 회귀의 계수는 로짓의 변화량이다. 확률이 아니라 오즈로 바꿔 읽는다.

- 다른 변수가 고정일 때 x1이 1 증가하면 오즈가 e^(b1)배가 된다. 이 e^(b1)이 오즈비(odds ratio)다.
- 오즈비가 1이면 영향이 없고, 1보다 크면 양성 오즈가 증가, 1보다 작으면 감소한다.
- 예: b1=0.693이면 e^0.693이 약 2이므로 x1이 1 늘 때마다 오즈가 약 2배가 된다. 확률이 2배가 되는 것이 아니다.
- 계수의 부호가 양이면 오즈비가 1보다 크고, 음이면 1보다 작다.

## 추정 방법

계수는 최소제곱법이 아니라 최대우도법(Maximum Likelihood Estimation)으로 추정한다. 관측된 0/1 결과가 나올 가능성(우도)을 가장 크게 만드는 계수를 반복 계산으로 찾는다. 해가 닫힌 식으로 나오지 않는다.

## 간단한 예

scikit-learn으로 적합하고 오즈비를 구하는 코드다. 참고로 `LogisticRegression`은 기본값으로 L2 규제가 걸려 있어, 통계 패키지가 내놓는 비규제 추정값과 계수가 다를 수 있다.

```python
import numpy as np
from sklearn.linear_model import LogisticRegression

X = np.array([[1], [2], [3], [4], [5], [6]])  # 학습 시간
y = np.array([0, 0, 0, 1, 1, 1])              # 합격 여부

model = LogisticRegression().fit(X, y)
print(model.predict_proba([[3.5]]))  # [불합격 확률, 합격 확률]
print(np.exp(model.coef_))           # 오즈비
```

## 시험 포인트

- 종속변수가 범주형(이진)일 때 쓰는 분류 모형이며, 출력은 0~1의 확률이다.
- 로짓 = ln(p/(1-p))가 설명변수의 선형 결합이다.
- 계수는 최대우도법으로 추정한다.
- 오즈비는 e^(계수)이고, 1보다 크면 오즈 증가, 1이면 영향 없음이다.
- 오즈비는 확률의 배수가 아니라 오즈의 배수다. p가 작을 때만 둘이 비슷하다.
- 선형회귀와 달리 잔차의 정규성·등분산성을 가정하지 않지만, 설명변수 간 다중공선성은 여전히 문제가 된다.
