## 정의

메모리 배치 전략(placement strategy)은 새 프로세스를 적재할 때 여러 빈 공간(hole) 중 어디에 넣을지 정하는 규칙이다. 연속 할당 방식에서 프로세스는 한 덩어리의 연속된 공간이 필요하므로, 어떤 hole을 고르느냐에 따라 이후 남는 공간의 모양이 달라진다.

## 세 가지 배치 전략

| 전략 | 선택 기준 | 특징 |
|---|---|---|
| 최초 적합(First-fit) | 앞에서부터 탐색해 처음 만나는, 들어갈 수 있는 hole | 탐색이 빠르다 |
| 최적 적합(Best-fit) | 들어갈 수 있는 hole 중 가장 작은 것 | 전체 탐색이 필요하고, 아주 작은 자투리가 많이 생긴다 |
| 최악 적합(Worst-fit) | 가장 큰 hole | 남는 조각을 크게 유지하려는 의도지만, 큰 공간이 먼저 소진된다 |

## 예제로 비교

주소 순서대로 빈 공간이 100K, 500K, 200K, 300K, 600K이고, 프로세스가 212K, 417K, 112K, 426K 순서로 도착한다고 하자.

```text
최초 적합: 212K -> 500K (288K 남음)
           417K -> 600K (183K 남음)
           112K -> 288K (176K 남음)
           426K -> 들어갈 hole 없음 (대기)

최적 적합: 212K -> 300K (88K 남음)
           417K -> 500K (83K 남음)
           112K -> 200K (88K 남음)
           426K -> 600K (174K 남음)  전부 적재

최악 적합: 212K -> 600K (388K 남음)
           417K -> 500K (83K 남음)
           112K -> 388K (276K 남음)
           426K -> 들어갈 hole 없음 (대기)
```

이 입력에서는 최적 적합만 네 프로세스를 모두 적재했다. 다만 이것이 항상 최적 적합이 우월하다는 뜻은 아니다. 입력 순서에 따라 결과가 달라지며, 일반적으로 최초 적합과 최적 적합이 최악 적합보다 대체로 낫다고 알려져 있다.

## 단편화

단편화(fragmentation)는 메모리가 있는데도 쓰지 못하는 낭비를 말한다.

- **내부 단편화**: 할당된 영역 안에서 프로세스가 쓰고 남은 공간. 고정 분할 방식(예: 512K 칸에 400K 프로세스를 넣으면 112K가 낭비)이나 페이징의 마지막 페이지에서 발생한다.
- **외부 단편화**: 빈 공간의 총합은 충분하지만 흩어져 있어 연속 공간이 없는 상태. 가변 분할 방식과 세그먼테이션에서 발생한다. 위 예제에서 최초 적합이 426K를 못 넣은 것이 이 경우다.

## 해결 방법

- **통합(coalescing)**: 인접한 빈 공간을 하나로 합친다.
- **압축(compaction)**: 사용 중인 영역을 한쪽으로 모아 빈 공간을 하나로 만든다. 프로세스 재배치 비용이 크다.
- **페이징**: 프로세스를 고정 크기 페이지로 나눠 비연속 적재하므로 외부 단편화가 사라진다. 대신 마지막 페이지에 내부 단편화가 남는다.

## 시험 포인트

- 세 전략의 선택 기준을 주어진 hole 목록에 직접 적용하는 계산 문제가 자주 나온다. hole이 쪼개진 뒤 남은 크기를 반영해 다음 프로세스를 배치해야 한다.
- 내부 단편화는 고정 분할·페이징, 외부 단편화는 가변 분할·세그먼테이션과 짝지어 외운다.
- 외부 단편화의 해결책은 압축, 내부 단편화의 완화책은 분할 크기 조정이다.
