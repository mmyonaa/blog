## 이상값이란

이상값(outlier)은 다른 관측치와 동떨어진 값이다. 입력 오류나 측정 오류처럼 걸러야 하는 경우도 있고, 실제로 발생한 극단적 사건처럼 보존해야 하는 경우도 있다. 그래서 탐지와 처리는 별개의 판단이다. 평균·분산·회귀계수는 이상값에 민감하므로 모델링 전에 반드시 확인한다.

## 탐지 방법 1: IQR (사분위수 범위)

데이터를 정렬해 1사분위수(Q1)와 3사분위수(Q3)를 구하고, 그 차이를 IQR이라 한다. 박스플롯의 수염 기준이 바로 이 방식이다.

```text
IQR = Q3 - Q1
하한 = Q1 - 1.5 x IQR
상한 = Q3 + 1.5 x IQR
하한 미만 또는 상한 초과 → 이상값
```

중앙에 가까운 50% 구간을 기준으로 삼기 때문에 극단값 자체의 영향을 덜 받는다. 정규분포 가정이 필요 없다는 점이 장점이다. 계수 1.5 대신 3을 쓰면 더 극단적인 값만 잡는다.

## 탐지 방법 2: Z-점수

평균과 표준편차로 각 값을 표준화한다.

```text
z = (x - 평균) / 표준편차
```

관례적으로 |z|가 3을 넘으면(경우에 따라 2~2.5) 이상값으로 본다. 정규분포에서 평균 ±3 표준편차 밖에 놓일 확률이 아주 작다는 데 근거한다. 약점은 두 가지다. 데이터가 정규분포에 가깝다는 전제가 필요하고, 이상값이 평균과 표준편차 자체를 끌어당겨 탐지를 방해한다(마스킹). 표본이 작을수록 이 문제가 커진다.

## 탐지 방법 3: ESD

ESD(Generalized Extreme Studentized Deviate)는 이상값이 여러 개일 수 있다고 보고, 정규분포를 가정한 통계 검정으로 반복 탐지한다.

1. 의심되는 이상값의 최대 개수 k를 미리 정한다.
2. 평균에서 가장 멀리 떨어진 값의 표준화 거리를 검정통계량으로 계산한다.
3. 그 값을 제거하고 남은 데이터로 2를 k번 반복한다.
4. 각 단계의 검정통계량을 임계값과 비교해, 유의한 마지막 단계까지의 값을 모두 이상값으로 판정한다.

Z-점수가 한 번에 판단하는 것과 달리, 하나씩 제거하며 다시 계산하므로 마스킹 문제를 완화한다.

## 간단한 예시

아래 코드는 numpy만 있으면 실행된다.

```python
import numpy as np

x = np.array([10, 12, 11, 13, 12, 11, 10, 95])
q1, q3 = np.percentile(x, [25, 75])
iqr = q3 - q1
low, high = q1 - 1.5 * iqr, q3 + 1.5 * iqr
print(x[(x < low) | (x > high)])  # [95]
```

## 처리 방식

- 삭제: 명백한 오류일 때. 표본이 줄어드는 비용이 있다.
- 대체: 결측으로 처리한 뒤 평균·중앙값 등으로 대치하거나, 경계값으로 제한(winsorizing)한다.
- 변환: 로그 변환 등으로 극단값의 영향을 줄인다.
- 별도 분석: 이상값 자체가 관심 대상일 때(이상 거래 탐지 등).

## 시험 포인트

- IQR 기준은 Q1 - 1.5 x IQR, Q3 + 1.5 x IQR이며 박스플롯과 연결된다.
- Z-점수는 정규성 가정이 필요하고, 이상값에 평균·표준편차가 흔들린다.
- ESD는 이상값이 여러 개일 때 사용하며 최대 개수를 사전에 지정한다.
- 이상값이라고 무조건 제거하지 않는다. 원인을 먼저 파악한다.
